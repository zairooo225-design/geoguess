# Interactive Learning Game

A real-time, interactive quiz and learning game built with React, Socket.IO, and Tailwind CSS. Players join rooms via a code, compete on questions, maintain streaks, and can form teams for bonus points. 

## 🚀 Features

- **Real-Time Multiplayer:** Built with Socket.IO for instant guess submission and score updates.
- **AI Name Verification:** Automatic validation of player usernames to keep the game safe and fun!
- **Teacher Dashboard:** Create games, view live student connectivity, and track performance.
- **Mobile Optimized:** Fluid and responsive UI, engineered to look and feel like a native app on mobile screens.
- **Engaging Visuals:** Framer Motion-powered animations for satisfying streaks, round results, and interactions.

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express, Socket.IO
- **Database / Auth:** Firebase Authentication

## 📱 Mobile Experience
This app is designed mobile-first, ensuring all touch targets, input fields, and animations perform flawlessly on mobile browsers.

## 🏃‍♂️ Running Locally

1. Clone this repository.
2. Ensure you have Node.js installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server (which handles both Express & Vite):
   ```bash
   npm run dev
   ```
